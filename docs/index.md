# LTS: Long-Term Stack / Support

My project templates and tooling preferences.

- **[Templates](templates.md)**: Project templates for consistent structure
- **[Preferences](preferences.md)**: Tooling and system preferences

## Why?

- **Consistency**: Same structure across projects reduces cognitive load
- **Automation**: Templates encode best practices; less to remember
- **Documentation**: Preferences are written down, not tribal knowledge
- **Agent-friendly**: AI assistants can use these templates effectively
- **Evidence-based**: Tool timelines derived from actual git history
